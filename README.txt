DSA Learning Hub
================

Files:
- index.html
- styles.css
- script.js

How to use:
1. Keep all three files in the same folder.
2. Double-click index.html to open it in Chrome/Edge/Firefox.
3. Topic completion and student reviews are stored in the browser using localStorage.

Included modules:
Dashboard, Introduction, Complexity Analysis, Arrays, Linked Lists, Stack, Queue, Trees, Graphs, Searching, Sorting, Recursion, Programming Lab, Visualization Lab, Practice Zone, DSA Cheat Sheet, Student Corner, and About.

Note about code execution:
The site is browser-based. Browsers cannot directly compile arbitrary C code without a compiler engine or server/API. The Programming Lab therefore provides an editable C area and real C compilation/execution through the GCC-based Wandbox API. It can later be connected to Judge0/Piston or a local compiler backend.
